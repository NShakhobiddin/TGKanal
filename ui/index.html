Postlar yopiq GitHub repoda saqlanadi. Kirish uchun repo nomi va GitHub tokenini kiriting — token faqat shu brauzerda saqlanadi.

Token qanday olinadi?
  1. github.com → Settings → Developer settings → Fine-grained tokens → Generate new token
  2. Nomi: pochtachi-panel, muddati: 1 yil
  3. Repository access: Only select repositories → faqat ma'lumotlar repo
  4. Permissions → Repository: Contents — Read and write, Actions — Read and write
  5. Generate → tokenni nusxalab shu yerga qo'ying
